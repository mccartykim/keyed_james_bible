how it was keyed

Verse selection is done by Jev, which returns probabilities over options rather than text. The verse text is clipped from a local copy of the King James Version (public domain). No verses are generated.

I wasn't sure whether this is blasphemy or a useful Bible study tool, so I fed Jev the project's source and asked it. It said 0.07 that it is blasphemous and 0.33 that it is useful. So: probably not blasphemy, and probably not a study tool either. It is a near-hash — the selection is a distribution over 31,102 verses, and it does not know what any verse means.
